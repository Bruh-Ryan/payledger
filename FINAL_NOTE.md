## Build Instructions
To build the project, ensure you have:
- Java 21 installed
- Maven 3.8+ installed
- PostgreSQL running (or adjust application.yml to use an in-memory database for testing)

Then run:
```bash
cd payledger
mvn clean install
```

If you encounter disk space issues with dependency downloads, specify an alternative local repository:
```bash
mvn clean install -Dmaven.repo.local=D:/m2_repo
```

## Testing
Run the test suite with:
```bash
mvn test
```

## Running the Application
Start the application with:
```bash
mvn spring-boot:run
```

The API will be available at http://localhost:8080

## API Documentation
Once the application is running, you can access the Swagger UI at:
http://localhost:8080/swagger-ui.html
